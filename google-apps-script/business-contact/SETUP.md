# REVIA 法人・メディア問い合わせ専用Apps Script 設定手順

この手順では、無料相談予約システムとは別のGoogle Apps Scriptプロジェクトを新規作成します。既存の予約用Apps Scriptプロジェクトや予約用 `Code.gs` は変更しません。

## 1. 新しいApps Scriptプロジェクトを作成する

1. [Google Apps Script](https://script.google.com/) を開きます。
2. 「新しいプロジェクト」を押します。
3. プロジェクト名を `REVIA 法人問い合わせ` など、予約用と区別できる名前へ変更します。
4. 既存の無料相談予約用プロジェクトを開いていないことを、画面上部のプロジェクト名で確認します。

## 2. 専用コードを貼り付ける

1. 新しいプロジェクト内の `Code.gs` を開きます。
2. 初期表示されているコードを削除します。
3. このフォルダの [Code.gs](./Code.gs) 全文を貼り付けます。
4. 保存ボタンを押します。

この専用コードには、法人問い合わせの入力検証とメール送信だけが含まれます。Zoom、Googleカレンダー、予約スプレッドシートは使用しません。

## 3. 送信先メールアドレスを設定する

1. Apps Script画面左側の歯車アイコン「プロジェクトの設定」を開きます。
2. 「スクリプト プロパティ」まで移動します。
3. 「スクリプト プロパティを追加」を押します。
4. 次の値を設定します。

| プロパティ | 値 |
| --- | --- |
| `BUSINESS_CONTACT_EMAIL` | `revia2026.mail@gmail.com` |

5. 「スクリプト プロパティを保存」を押します。

このプロパティが未設定の場合も、`revia2026.mail@gmail.com` へ送信されます。将来、独自ドメインメールへ変更する場合は `BUSINESS_CONTACT_EMAIL` の値だけを変更してください。

## 4. タイムゾーンを確認する

1. 「プロジェクトの設定」を開きます。
2. タイムゾーンを `（GMT+09:00）東京` に設定します。
3. 保存します。

## 5. 新しいWebアプリとしてデプロイする

1. 右上の「デプロイ」から「新しいデプロイ」を選びます。
2. 「種類の選択」で「ウェブアプリ」を選びます。
3. 説明へ `法人問い合わせフォーム初回公開` などと入力します。
4. 「次のユーザーとして実行」は「自分」を選びます。
5. 「アクセスできるユーザー」は、公開サイトから認証なしで利用できる「全員」を選びます。
6. 「デプロイ」を押します。
7. 初回の権限確認では、法人問い合わせの送信に使用するGoogleアカウントで承認します。
8. 発行された、末尾が `/exec` のウェブアプリURLを控えます。

予約用WebアプリのURLと取り違えないようにしてください。

## 6. contact.jsへURLを設定する

1. サイト側の `contact.js` を開きます。
2. ファイル上部の `BUSINESS_CONTACT_ENDPOINT` を探します。
3. 空の文字列へ、手順5で発行された `/exec` URLを貼り付けます。

```js
const BUSINESS_CONTACT_ENDPOINT = "https://script.google.com/macros/s/ここへ専用URL/exec";
```

変更するURLはこの1か所だけです。予約用 `script.js` の `bookingEndpoint` は変更しません。

## 7. 専用Webアプリを直接確認する

1. 発行された `/exec` URLをブラウザで開きます。
2. `"ok":true` と `REVIA business contact endpoint is running.` が表示されることを確認します。
3. URL末尾へ `?mode=business-contact-config` を付けて開きます。
4. `"ok":true` と `"contactEmail":"revia2026.mail@gmail.com"` が表示されることを確認します。

設定確認APIが返すのは公開用メールアドレスだけです。スクリプトプロパティ全体や秘密情報は返しません。

## 8. フォーム送信を確認する

1. `contact.html` を開きます。
2. 必須項目を入力し、プライバシーポリシーへの同意へチェックします。
3. 「問い合わせを送信する」を押します。
4. 画面に次の文が表示されることを確認します。

```text
お問い合わせを受け付けました。
内容を確認のうえ、必要に応じてご連絡いたします。
```

5. `BUSINESS_CONTACT_EMAIL` で設定したメールアドレスへ通知が届くことを確認します。
6. メール件名で問い合わせ種別を判別できることを確認します。
7. 本文に、問い合わせ種別、会社・団体名、氏名、メールアドレス、電話番号、件名、問い合わせ内容、受付日時が含まれることを確認します。

## 9. 予約システムに影響がないことを確認する

1. トップページの無料相談フォームを開きます。
2. 空き時間が従来どおり表示されることを確認します。
3. `script.js` の `bookingEndpoint` が変更されていないことを確認します。
4. 既存の予約用Apps Scriptが再デプロイされていないことを確認します。

法人問い合わせのコード更新時は、この専用プロジェクトだけを新バージョンとして再デプロイしてください。
